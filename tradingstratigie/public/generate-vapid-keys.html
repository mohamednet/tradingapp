📋 How to Add Keys to Your App

  1. Open your .env file
  2. Add these lines at the end: 
    # Web Push Notification Keys
VAPID_PUBLIC_KEY=your_public_key_here
VAPID_PRIVATE_KEY=your_private_key_here
VAPID_SUBJECT=mailto:your-email@example.com
  3. Replace your_public_key_here with the Public Key above
  4. Replace your_private_key_here with the Private Key above
  5. Replace your-email@example.com with your actual email
  6. Save the file and restart your server
